# The First Garden — gates

Each gate is one self-contained HTML page (no network, saves only in the browser). Open the file directly in a browser.

| Gate | File | Adds |
|---|---|---|
| 3 · The Dwelling | `sonolumina_gate3.html` | Gathering, building the house in five stages, night rest, the seventh day kept. See `docs/gate3-handoff.md`. |
| 4 · Sound & Light | `sonolumina_gate4.html` | Scripture for each moment (KJV, in the file), live music and light that follow the meaning of the words. See `docs/gate4-handoff.md`. |
| 5 · Daily Bread | `sonolumina_gate5.html` | Shared morning and evening meals, tending the fruit trees, caring for the deer, the Day book. See `docs/gate5-handoff.md`. |

Each later gate carries the earlier save forward (Gates 3–4 save as `sonolumina.first-garden.v3`, Gate 5 as `...v4`). Older saves are migrated and left untouched.

Note: the earlier copy of `sonolumina_gate3.html` in this folder was the published Gate 4 page, wrapped by the artifact host. It has been replaced by the real Gate 3 file, and Gate 4 now has its own file.
